# CleartrackApps storefront

Static single-page storefront. No build step required to serve — `index.html` is committed output.

- `index.html` — generated by `python3 build.py` (edit copy/links in `build.py`, then rerun)
- `base.css` / `style.css` / `app.js`
- `assets/og-image.png` — generated from `og-source.html` via `python3 qa.py og`
- `qa.py` — Playwright screenshots + overflow checks (dev only)

All paths are relative, so it can be dropped into a GitHub Pages repo root as-is.
